Zorn's Lemma

Zorn's lemma is a statement equivalent to the axiom of choice and the well-ordering principle. It is often used in algebra for maximality theorems. For example, for showing that every vector space has a maximal linearly independent set (i.e. a basis), or to show that every ideal of a ring can be extended to a maximal ideal.

Statement

A partial ordered set, or poset, is a pair $(P,\le)$ with a set $P$ and a binary relation $\le$ on $P$ satisfying:

  • Reflexivity. For all $x \in P$, $x \le x$;
  • Transitivity. For all $x,y,z \in P$, if $x \le y$ and $y \le z$, then $x \le z$;
  • Antisymmetry. For all $x,y \in P$, if $x \le y$ and $y \le x$, then $x = y$.

A set $C \subset P$ is a chain iff $C$ is linearly ordered by $\le$. That is, for all $x,y \in C$, we have $x \le y$ or $y \le x$. For a set $A \subset P$ and an element $x \in P$:

  • $x$ is an upper bound of $A$, denoted $A \le x$, iff, for all $a \in A$, $a \le x$;
  • $x$ is a lower bound of $A$, denoted $x \le A$, iff, for all $a \in A$, $a \le x$;
  • $x$ is a maximal element of $A$ iff $x \in A$ and, for all $a \in A$, if $x \le a$, then $x = a$;
  • $x$ is a minimal element of $A$ iff $x \in A$ and, for all $a \in A$, if $a \le x$, then $a = x$.

A set can have multiple maximal or minimal elements. For example, if we set $P = \pow(\NN)$ and $X \le Y \Leftrightarrow X \subset Y$, and we set $A$ to be the set of subsets of $\NN$ with cardinality $\le 6$, then every six element set in $A$ is maximal.

A poset $(P,\le)$ is inductive iff all chains in $P$ have an upper-bound. The poset $(P,\le)$ is reductive iff every chain has a lower-bound. Zorn's lemma is the following statement:

Every inductive poset has a maximal element.

There are a few variations on this, including:

  • Strong Zorn's lemma. For every element $a \in P$ of an inductive poset, there is a maximal element $m \ge a$;
  • Hausdorff's maximality principle. Every poset has a $\subset$-maximal chain.;
  • Inverse Zorn's lemma. Every reductive poset has a minimal element.

Zorn's Lemma implies AC

In this part, we'll show that Zorn's lemma implies the axiom of choice. Let $f: A \twoheadrightarrow B$ be a surjection for which we want to find a section. Define a poset $(P,\le)$ as follows:

Elements of $P$ are pairs $(S,g)$ with $S \subset B$ and $g: S \to A$ so that $f(g(x)) = x$ for all $x \in S$. We let $(S,g) \le (T,h)$ iff $S \subset T$, and $g(x) = h(x)$ for all $x \in S$.

We verify $(P,\le)$ is inductive. Let $C$ be a chain in $P$. Note that all functions $h$ for $(T,h)$ in $C$ are compatible. Define an upper-bound $(S,g)$ for $C$ as follows: $S = \bigcup_{(T,h) \in C} T$, and $g(x) = h(x)$ for all $(T,h) \in C$ and $x \in T$. Clearly, $(T,h)$ is an upper-bound.

As $(P,\le)$, it has an upper-bound. Let $(M,m)$ be as such. Assume, towards contradiction, $M \neq B$. Let $b \in B \setminus M$. As $f$ is a surjection, there is some $a \in A$ for which $f(a) = b$. Define $m': M \cup \{b\} \to A$ as follows: $m'(x) = m(x)$ for $x \in M$, and $m'(b) = a$. Then, $(M,m) < (M \cup \{b\},m')$, contradicting $(M,m)$ being a maximal element. So, we have $M = B$, and $m: B \to A$. Clearly, $m$ is a section of $f$.

Zorn's Lemma implies WOP

Let $B$ be the set we want to well-order. Define a poset $(P,\le)$ as follows:

Elements of $P$ are pairs $(S,<_S)$ with $S \subset B$ and with $<_S$ a well-order on $S$. We set $(S,<_S) \le (T,<_T)$ iff $S \subset T$, and the identity map $S \to T$ is a segment.

We verify $(P,\le)$ is inductive. Let $C$ be a chain in $P$. We define an upper-bound $(S,<_S)$ for $C$ as follows: $S = \bigcup_{(T,<_T) \in C} T$, and $x <_S y$ iff $x <_T y$ for some $(T,<_T;) \in C$ with $x,y \in T$ (some element of $C$ must contain $x$, and some element must contain $y$, and one of those must extend the other, i.e. contain both). You'll verify in the exercises that $<_S$ is a well-order.

As $P$ is inductive, it has an upper-bound $(M,<_M)$. Clearly, $M = B$, and $<_M$ is a well-order on $B$, as desired.

WOP implies Zorn's Lemma

For a poset $(P,\le)$, a strict upper-bound for a set $A \subset P$ is an upper-bound $A \le x$ with $x \notin A$, for which we write $A < x$.

Let $(P,\le)$ be an inductive poset for which we want to find a maximal element. Let $\triangleleft$ be a well-order of $P$ and let $\beta = \aleph(P)$. By recursion, define a function $f: \beta \to P$. Assume $f(y)$ for $y < x$ has been defined. Let

\[C = \{f(y) \mid y < x\}\]

Then:

  1. If $C$ is not a chain, set $f$ to be a dummy value, such as the $\triangleleft$-minimal element of $P$;
  2. If $C$ is a chain and does not have a strict upper-bound, set $f(x)$ to be the $\le$-maximal element of $C$;
  3. If $C$ is a chain and does have a strict upper-bound, set $f(x)$ to be the $\triangleleft$-minimal strict upper-bound of $C$.

By induction on $\beta$, the image $\im f$ is a chain in $(P,\le)$. So, the first case in the definition above is never reached. As $|P| \nleq \beta$, the function $f: \beta \to P$ is not an injection, so the third case isn't always applied. So, the second case is reached at least once. Therefore, $\im f$ has no strict upper-bound. As $(P,\le)$ is inductive, the set $\im f$ does have some upper-bound, which (as it is not strict) is a maximal element of $(P,\le)$.

Verify that the upper-bound constructed in the part Zorn's Lemma implies WOP is a well-order. Further, suppose we had defined $(S,<_S) \le (T,<_T)$ iff $S \subset T$ and $(<_S) \subset (<_T)$. Give an example of a set $B$ and a chain $C \subset P$ that has no upper-bound in this ordering.

A filter on a set $X$ is a family $F \subset \pow(X)$ of subsets of $X$, satisfying the following four conditions:

  • $\varnothing \notin F$;
  • $X \in F$;
  • If $A \subset B \subset X$ and $A \in F$, then $B \in F$;
  • If $A,B \in F$, then $A \cap B \in F$.

A filter $U$ on $X$ is an utlrafilter iff the following additional condition is satisfied:

  • For all $A \subset X$, either $A \in U$ or $X \setminus A \in U$.

Using Zorn's lemma, show that every filter $F$ on $X$ can be extended to an ultrafilter $U \supset F$ on $X$.
