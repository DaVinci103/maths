Ordinals

Linear Orders

Suppose $(L,<)$ is a pair with a set $L$ and a binary relation $(<) \subset L \times L$ on $L$. For $a,b \in L$, we write $a < b$ for $(a,b) \in (<)$. We call $(L,<)$ a linear order iff it satisfies:

  • Transitivity. If $a < b$ and $b < c$, then $a < c$;
  • Trichotomy. For $a,b \in L$, exactly one of the following holds:
    1. $a < b$;
    2. $a = b$;
    3. $b < a$.

Examples of linear orders are $(\NN,<)$, the order of natural numbers, $(\QQ,<)$, the order of rational numbers, and $(\varnothing,<)$, the empty ordering ($(<) = \varnothing$ is the unique subset of $\varnothing \times \varnothing$).

If the ordering $<$ is clear from context, we sometimes identify the linear order $(L,<)$ with the set $L$.

Intuitively, a linear order looks like points on a horizontal line. For points $x,y \in X$, $x < y$ is interpreted as $x$ is to the left of $y$. Transitivity then states that, if $a$ is to the left of $b$, which is to the left of $c$, then $a$ is to the left of $c$. Trichotomy states that any two points are either the same point, or one is to the left of the other, without any of these options conflicting.

One immediate consequence of trichotomy is irreflexivity: for any point $x$, we have $x = x$, therefore $x \not < x$. We call irreflexive orderings strict. A non-strict ordering is an ordering that is reflexive. We often use $<$ for strict orderings, and $\le$ for non-strict orderings. What we have defined above is therefore, more accurately, a strict linear order, while a non-strict linear order would be a pair $(L,\le)$ with a set $L$ and a binary relation $\le$ that is transitive, antisymmetric and total ($a \le b$ or $b \le a$ for all $a,b \in L$, where $a = b$ if both hold). Strict and non-strict linear orders encode the same information, only in different ways: given a strict linear order $<$, we can define a non-strict linear order $\le$ by $x \le y$ iff $x < y$ or $x = y$, and given a non-strict linear order $\le$, we can define a strict linear order $<$ by $x < y$ iff $x \le y$ and $x \neq y$. Whether to use strict or non-strict orderings mostly comes down to personal preference.

On each of the standard finite sets $\mathbf{n} = \{0_{\mathbf{n}}, \ldots, (n-1)_{\mathbf{n}}\}$, we define a linear order $<$ where $0_{\mathbf{n}} < \cdots < (n-1)_{\mathbf{n}}$. We call this the standard order on $\mathbf{n}$, and denote it as $n = (\mathbf{n},<)$. Note that this isn't the only linear order on $\mathbf{n}$: $\mathbf{2}$ has a second linear order where $1_{\mathbf{2}} < 0_{\mathbf{2}}$. Generally, $\mathbf{n}$ has $n!$ ($n$ factorial) linear orders. However, these linear orders are all isomorphic, i.e. the same up to relabeling of the elements.

For linear orders $(A,<)$ and $(B,<)$, an embedding is a function $f: A \to B$ for which, for all $a,b \in A$, if $a < b$, then $f(a) < f(b)$. Embeddings are necessarily injective, and the composition of two embeddings is again an embedding. An isomorphism of linear orders is an embedding $f: A \to B$ for which there exists an embedding $g: B \to A$ with $g \circ f = \id_A$ and $f \circ g = \id_B$. We call such a $g: B \to A$ the inverse of $f$, and write it $f^{-1}$. If there exists an isomorphism between $A$ and $B$, we call $A$ and $B$ isomorphic.

Well-Orders

Given a linear order $(L,<)$ and a point $a$, we define:

\[(a) = \{b \in L \mid b < a\}\]

to be the set of points in $L$ that are below $a$. We say a subset $S \subset L$ is inductive iff, for all $a \in L$, if $(a) \subset S$, then $a \in S$.

To give an example, suppose we have an inductive set $S \subset \NN$ of natural numbers. We have $(0) = \varnothing$, and therefore $(0) \subset S$. By the definition of an inductive set, this implies $0 \in S$. However, since $(1) = \{0\}$, we now have $(1) \subset S$, and therefore $1 \in S$. And now, since $(2) = \{0,1\} \subset S$, we have $2 \in S$. This continues infinitely, and eventually we will have $S = \NN$. This is the principle of (strong) induction on $\NN$.

Now suppose we have the set of integers $\ZZ$ with its usual order, and let $S = \varnothing$ be the empty subset of $\ZZ$. For any integer $n$, we have $n-1 \in (n)$, and so no $(n)$ is empty. Therefore, for no $n \in \ZZ$ do we have $(n) \subset S$, and $S$ is vacuously inductive.

We say a linear order $(L,<)$ is a well-order iff for all inductive $S \subset L$, we have $S = L$. Examples of linear orders are the standard finite orders $n$ and the order of natural numbers $\NN$. A non-example is the ordered set $\ZZ$ of integers, as $\varnothing \subsetneq \ZZ$ is inductive. A (bit stranger) example of a well-order is $\overline{\NN} = \NN + \{\infty\}$, which is the natural numbers $\NN$ with a maximal element $\infty$ added. For all $n \in \NN$, we have $n < \infty$.

Properties of well-orders are often proven by induction. First, a set $S \subset L$ is defined of points with a desirable property. Then, $S$ is proven to be inductive. Last, we conclude $S = L$ by the definition of a well-order, and therefore every element of $L$ has the desirable property.

In the exercises, you'll be asked to prove the equivalence between $(L,<)$ being a well-order and every non-empty subset of $L$ having a minimal element. In the next parts, we assume this is given.

Recursion

If we have a linear order $(L,<)$, then we can define functions $f: L \to X$ by recursion. That is, we define $f(a)$ assuming the values $f(b)$ for $b < a$ are known. Formally, a recursive definition is a function

\[F: \sum_{a \in L} X^{(a)} \to X\]

that takes a point $a \in L$ and a function $g: (a) \to X$ as arguments, and gives an element $F(a,g) \in X$ as value. We then say $F$ defines a function $f: L \to X$ iff, for all $a \in L$,

\[f(a) = F(a,f|_{(a)})\]

Where $f|_{(a)}: (a) \to X$ is the function restriction of $f$ to $(a)$. We then have the following theorem:

If $(L,<)$ is a well-order and $X$ is a set, then every recursive definition $F: \sum_{a \in L} X^{(a)} \to X$ defines a unique function $f: L \to X$.

The proof of this theorem is quite technical, but I'll do my best to explain it. I'll first prove the second part: if $F$ defines a function, then that function is unique.

Suppose $F$ defines functions $f,g: L \to X$, aiming to show that $f = g$. By function extensionality, we want to show that $f(a) = g(a)$ for all $a \in L$. Define a set

\[S = \{a \in L \mid f(a) = g(a)\}\]

We want to show $S$ is inductive. Let $a \in L$ and suppose $(a) \subset L$. Then, $f|_{(a)} = g|_{(a)}$ and

\[f(a) = F(a,f|_{(a)}) = F(a,g|_{(a)}) = g(a)\]

and therefore $a \in S$. By definition of well-order, we have $S = L$ and therefore $f = g$.

For the second part, let $S \subset L$ be the set of $a \in L$ for which there exists a function $g: (a) \to X$ for which, for all $b < a$,

\[g(b) = F(b,g|_{(b)})\]

Note that, by transitivity, $(b) \subset (a)$, so the domain of $g|_{(b)}$ is $(b)$ (as opposed to a proper subset of $(b)$). For each $a \in S$, by the first part of this proof (applied to the well-order $((a),<)$), this function $g$ is unique and we'll denote it $f_a: (a) \to X$.

Now, let $a \in L$ and assume, aiming to show $S$ is inductive, that $(a) \subset S$. Define the function $g: (a) \to X$ by

\[g(b) = F(b,f_b)\]

Define $T \subset (a)$ to be the set of $b < a$ for which $g(b) = F(b,g|_{(b)})$. We want to show $T$ is inductive (in $((a),<)$), so let $b < a$ and assume $(b) \subset T$. Then, for $g|_{(b)}: (b) \to X$, we have $g|_{(b)}(c) = F(c,g|_{(b)}|_{(c)})$ so, by unicity in the first part of the theorem, $g|_{(b)} = f_b$. So, we have

\[g(b) = F(b,f_b) = F(b,g|_{(b)})\]

and therefore $b \in T$. Therefore, $T$ is inductive and, as $((a),<)$ is well-ordered, we have $T = (a)$. Thus, we have $a \in S$ witnessed by $g$. Therefore, $S$ is inductive and, as $(L,<)$ is a well-order, $S = L$. Now, define $f: L \to X$ by

\[f(a) = F(a,f_a)\]

$f$ is defined by $F$ by the same argument we used for $g$: for $a \in L$, we have $f|_{(a)} = f_a$ by unicity and induction, and therefore $f(a) = F(a,f|_{(a)})$ as desired.

Ordinals

With induction, we can prove the following theorem:

If well-orders are isomorphic, then they're isomorphic in a unique way.

Let $(A,<)$ and $(B,<)$ be well-orders and let $f,g: A \to B$ be isomorphisms. Define

\[S = \{a \in A \mid f(a) = g(a)\}\]

For $a \in A$, assume $(a) \subset S$, aiming to show that $a \in S$. Towards contradiction, assume $a \notin S$ and therefore $f(a) \neq g(a)$. By trichotomy in $B$, we have either $f(a) < g(a)$ or $g(a) < f(a)$. Both cases are symmetrical, so assume, WLOG, that $f(a) < g(a)$. Then, as $g$ is an isomorphism, there must be some $b \in A$ for which $g(b) = f(a)$. We have $g(b) < g(a)$, and therefore $b < a$ (apply the inverse of $g$ on both sides, and use the fact that that inverse is an embedding). So, we have $b \in (a)$ and therefore $b \in S$. So, we have $f(b) = g(b) = f(a)$, which contradicts $f$ being injective. Therefore, we must have $a \in S$, and so $S$ is inductive. Thus, we have $S = A$ and $f = g$.

Compare this with the situation with sets: two sets $A$ and $B$ can have many bijections $A \leftrightarrow B$, but well-orders are only isomorphic in a unique way. So, although sets form only a large groupoid, the collection of well-orders are already a large set. In the first chapter, we defined $\Card$ as the set-truncation of the large groupoid of sets, but no such truncation is needed here.

Given a universe $\Univ$, we define $\Ord = \Ord_{\Univ}$ to be the set of $\Univ$-small well-orders (well-orders $(L,<)$ where $L$ is a $\Univ$-small set), and we say well-orders $A$ and $B$ are identical in $\Ord_{\Univ}$ iff they're isomorphic.

Elements of $\Ord$ are called ordinals. We often use Greek letters in the beginning of the alphabet, such as $\alpha,\beta,\gamma$, to denote ordinal numbers. For ordinals $\alpha,\beta \in \Ord$ and points $a \in \alpha$ and $b \in \beta$, if $\alpha = \beta$, then $a = b$ iff the unique isomorphism $\alpha \to \beta$ sends $a$ to $b$. Like $\Card$, the set $\Ord$ is a large set.

We identify finite ordinals with natural numbers $n = (\mathbf{n},<)$. We write $\omega$ for the ordinal $(\NN,<)$. The ordinal corresponding to $\overline{\NN} = \NN + \{\infty\}$ is denoted $\omega+1$, this notation will be explained later.

Ordering

For ordinals $\alpha$ and $\beta$ in $\Ord$, we write $\alpha \preceq \beta$ iff there is an embedding $f: \alpha \to \beta$. We write $\alpha \prec \beta$ iff $\alpha \preceq \beta$ and $\beta \not \preceq \alpha$. The main result of this chapter is that $(\Ord,\prec)$ is a (large) ordinal.

Though isomorphisms of well-orders are unique, embeddings are not. For example, for finite well-orders $k$ and $n$ with $k \le n$, there are $\binom{n}{k} = \frac{n!}{k!(n-k)!}$ embeddings from $k$ to $n$. However, of the embeddings $\alpha \to \beta$, we regard one as the canonical embedding.

We say an embedding of ordinals $f: \alpha \to \beta$ is a segment iff, for all $a \in \alpha$ and all $b < f(a)$, there is some $a' \in \alpha$ with $f(a') = b$. Terminology might differ, sometimes the image of $f$ is called a segment, and sometimes the term initial segment is used instead. We will use segment to refer to the embedding $f: \alpha \to \beta$ as described above. We have the following theorem:

For ordinals $\alpha$ and $\beta$, there exists a segment $f: \alpha \to \beta$ iff $\alpha \preceq \beta$. Moreover, this segment is unique. Composing segments gives a segment.

First, if $f: \alpha \to \beta$ is a segment, then $f$ witnesses $\alpha \preceq \beta$. So, assume $\alpha \preceq \beta$, aiming to define a segment $f: \alpha \to \beta$. Assume, WLOG, $\beta$ is non-zero. We define a recursive definition

\[F: \sum_{x \in \alpha} \beta^{(x)} \to \beta\]

Let $x \in \alpha$ and let $h: (x) \to \beta$, aiming to define $F(x,h)$. Define

\[X = \{y \in \beta \mid \forall x_0 < x. h(x_0) < y\}\]

to be the set of all $y \in \beta$ that are above the image of $h$ in $\beta$. There are two cases: either $X$ is empty, or $X$ is non-empty. If $X$ is empty, then define $F(x,h)$ to be the minimal element of $\beta$. Otherwise, if $X$ is non-empty, then it has a minimal element, so define $F(x,h)$ to be the minimal element of $X$. The recursive definition $F$ uniquely defines a function $f: \alpha \to \beta$, i.e.

\[f(x) = F(x,f|_{(x)})\]

We want to show that $f$ is an embedding, and that it is a segment. By $\alpha \preceq \beta$, there is some embedding $g: \alpha \to \beta$. By induction, we prove that, for $x \in \alpha$, $g(x) \not < f(x)$. Define

\[S = \{x \in \alpha \mid g(x) \not < f(x)\}\]

Let $x \in \alpha$ and assume $(x) \subset S$. Let $X$ be as above, with $h = f|_{(x)}$. If $X$ is empty, then $f(x)$ is the minimal element of $\beta$, and therefore $g(x) \not < f(x)$ and $x \in S$. If $X$ is non-empty, then let $m$ be the minimal element of $X$. We have $f(x) = m$. By $(x) \subset X$, we can see $X$ is a superset of

\[X_g = \{y \in \beta \mid \forall x_0 < x. g(x_0) < y\}\]

Let $m_g$ be the minimal element of $X_g$. We have that $m_g \not < m$ ($m$ is minimal in $X$, and $m_g \in X$). Since $g$ is an embedding, we have $g(x) \in X_g$, and therefore $g(x) \not < m_g$. By transitivity, we have $g(x) \not< m = f(x)$ as desired. Therefore, $x \in S$. The set $S$ is inductive, and therefore $S = \alpha$.

Let $x \in \alpha$. We prove that

\[X = \{y \in \beta \mid \forall x_0 < x. f(x_0) < y\}\]

is non-empty. Since $g(x) \not < f(x)$, we have $g(x) \in X$, and therefore $X$ is non-empty. To prove $f$ is an embedding, let $a,b \in \alpha$ and assume $a < b$, aiming to prove $f(a) < f(b)$. If we take $x = b$, then the set $X$ above is non-empty, and therefore $f(b) \in X$. In particular, choosing $x_0 = a$, we obtain $f(a) < f(b)$ as desired.

For the second part of the proof, we want to show that $f$ is a segment. Let $a \in \alpha$ and define

\[S = \{b \in (f(a)) \mid \exists a' \in \alpha. f(a') = b\}\]

We want to show $S$ is inductive in $(f(a))$. Let $b < f(a)$ and suppose $(b) \subset S$. For each $b_0 < b$, there is some $a_0 \in \alpha$ for which $f(a_0) = b_0$. Since $f$ is injective, this $a_0$ is unique and we write it $a(b_0)$. Define

\[Y = \{x \in \alpha \mid \forall b_0 < b. a(b_0) < x\}\]

The set $Y$ is non-empty, as $a \in Y$, and therefore it has a minimal element $a'$. By definition of $f$, $f(a')$ is the minimal element of

\[X = \{y \in \beta \mid \forall x_0 < a'. f(x_0) < y\}\]

We now aim to prove $b$ is this minimal element. For each $b_0 < b$, we have that $f(a(b_0)) = b_0$, and $a(b_0) < a'$ by definition of $a'$. Therefore, $b_0 \notin X$. For $x_0 < a'$, we have that $x_0 \le a(b_0)$ for some $b_0$. Therefore, $f(x_0) \le b_0$ for some $b_0$ and, by transitivity, $f(x_0) < b$. So, we have $b \in X$ and thus $f(a') = b$. We have $b \in S$. Since $S$ is inductive, we have $S = (f(a))$, which proves $f$ is a segment.

The last part of the theorem will be an exercise for the reader.

Segments give an alternative definition of $\preceq$: for ordinals $\alpha$ and $\beta$, we have $\alpha \preceq \beta$ iff there exists a segment $f: \alpha \to \beta$. Furthermore, for $\alpha \preceq \beta$ witnessed by the segment $f: \alpha \to \beta$, $a \in \alpha$ and $b \in \beta$, we define $a = b$ iff $f(a) = b$. This definition is motivated by the theorem above, showing that segments are unique and (so there is no ambiguity in which segment to choose), and that compositions of segments are segments (so if $a=b=c$ with $a \in \alpha$, $b \in \beta$ and $c \in \gamma$, and $\alpha \preceq \beta \preceq \gamma$, then $a=c$). Sometimes, the use of $a=b$ this way can be ambiguous: subsets of well-orders are well-orders, so if $A \subset \alpha$, for $a \in A$ and $b \in \alpha$, it might be unclear whether $a=b$ means that $i(a)=b$ where $i: A \hookrightarrow \alpha$ is the set inclusion, or $f(a)=b$ where $f: A \to \alpha$ is the segment. In this case, we interpret it as the first, i.e. $a = b$ iff $i(a) = b$ where $i$ is the inclusion.

Exercises

Let $f: A \to B$ be an embedding of linear orders. Prove $f$ is injective.

Let $f: A \to B$ be an embedding of linear orders. Prove the following are equivalent:

  1. $f$ is an isomorphism;
  2. $f$ is injective.

Let $(A,<_A)$ be a well-order and let $B \subset A$. Define the relation $<_B$ on $B$ by: $a <_B b$ iff $a <_A b$. Prove that $(B,<_B)$ is a well-order.

Let $(L,<)$ be a linear order. For $X \subset L$, we say $x \in X$ is a minimal element iff, for all $y \in X$, $y \not < x$. Show that the following are equivalent:

  1. $(L,<)$ is well-ordered ($L$ is the only inductive subset);
  2. Every non-empty subset $X \subset L$ has a minimal element.

Let $f,g: \alpha \to \beta$ be segments. Prove that $f = g$. Let $h: \beta \to \gamma$ be a segment. Prove that $h \circ f: \alpha \to \gamma$ is a segment.
