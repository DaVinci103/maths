Ordinal Topology

In the chapter Ordinals, we explored the basic theory of ordinals. We defined what well-orders and ordinals are and have proven the class $\Ord$ of small ordinals is itself a large ordinal. We briefly looked at arithmetic with ordinals. In this chapter, we expand on the theory of ordinals by exploring their topology, as well as expanding on ordinal arithmetic. We assume the reader has basic knowledge of topology. If not, the first part briefly explains all the topology needed in this chapter.

General Topology

A topology is a pair $(X,\cT)$ with a set $X$ and a family $\cT \subset \pow(X)$ of subsets of $X$, satisfying the following conditions:

  • For a family $F \subset \cT$, we have $\bigcup F \in \cT$;
  • For $A,B \in \cT$, we have $A \cap B \in \cT$;
  • $X \in \cT$.

Elements of $\cT$ are called open sets. Thus, arbitrary unions of open sets are open, binary intersections of open sets are open and $X$ is open. For a point $x \in X$, we call a set $U \subset X$ a neighbourhood of $x$ iff there is some open set $O \in \cT$ for which $x \in O$ and $O \subset U$.

  • A set $C \subset X$ is closed iff $X \setminus C$ is open;
  • A set $C \subset X$ is clopen iff $C$ is closed and open;
  • Given a set $A \subset X$, its interior $\overset{\circ}{A}$ is the largest open set contained in $A$;
  • Given a set $A \subset X$, its closure $\overline{A}$ is the largest closed set containing $A$;
  • A set $D \subset X$ is dense iff $\overline{D} = X$;
  • A set $R \subset X$ is regular open iff $\overset{\circ}{\overline{R}} = R$;
  • A set $N \subset X$ is nowhere dense (nwd) iff $\overset{\circ}{\overline{N}} = \varnothing$;
  • Given a set $A \subset X$, its boundary is the set $\partial A := \overline{A} \setminus \overset{\circ}{A}$

Thus, we have:

\[\begin{array}{rcl} \overset{\circ}{A} &=& \bigcup \{O \subset X \mid O \textrm{ open} \wedge O \subset A\} \\ \overline{A} &=& \bigcap \{C \subset X \mid C \textrm{ closed} \wedge A \subset C\} \end{array}\]

For a set $A \subset X$, a limit or accumulation point of $A$ is a point $x \in X$ for which, for all neighbourhoods $U$ of $x$, there is some point $y \in A \cap U$ for which $y \neq x$. The derivative of $A$, denoted $A'$, is the set of accumulation points of $A$.

For a set $X$, a basis on $X$ is a family $\cB \subset \pow(X)$ of subsets of $X$ satisfying the following conditions:

  • For $A,B \in \cB$, we have $A \cap B \in \cB$;
  • $\bigcup \cB = X$.

We call elements of $\cB$ basic open sets. Given a basis $\cB$, we define the topology

\[\cT_{\cB} := \left\{\bigcup F \mid F \subset \cB\right\}\]

In this case, we call $\cB$ is a basis for $\cT_{\cB}$. Note a topology can have different basises.

Given a set $X$, the discrete topology on $X$ is $\cT_{\textit{discrete}} = \pow(X)$. The indiscrete topology is $\cT_{\textit{indiscrete}} = \{\varnothing,X\}$.

An open cover of a topology $(X,\cT)$ is a family $\Sigma \subset \cT$ of open sets with $\bigcup \Sigma = X$. The topology $X$ is compact iff every open cover $\Sigma$ has a finite open subcover $\Sigma_0 \subset \Sigma$.

Let $(X,\cT_0)$ and $(Y,\cT_1)$ be topologies. A function $f: X \to Y$ is said to be continuous iff, for all open $O \in \cT_1$, the inverse image $f^{-1}(O) = \{x \in X \mid f(x) \in O\}$ is open (i.e. $f^{-1}(O) \in \cT_0$). A function $f: X \to Y$ is a homeomorphism iff there exists a continuous function $g: Y \to X$ with $g \circ f = \id_X$ and $f \circ g = \id_Y$. Although a homeomorphism is bijective, not every bijective continuous map is a homeomorphism. Take e.g. the identity function $\id_X: X \to X$ from the discrete topology $(X,\cT_{\textit{discrete}})$ to the indiscrete topology $(X,\cT_{\textit{indiscrete}})$, where $X$ has at least two points.

Order Topology

Let $(L,<)$ be a linear order. Write $[L]$ for $L + \{-\infty,\infty\}$ with ordering extending $L$ by $-\infty < a < \infty$ for all $a \in L$. For $a,b \in [L]$ with $a < b$, we define the open interval

\[(a,b) := \{x \in L \mid a < x < b\}\]

We define a basis for the topology on $L$,

\[\cB = \{(a,b) \mid a,b \in [L] \wedge a < b\}\]

The topology $\cT$ induced by $\cB$ is called the order topology on $L$. Explicitely, a set $O \subset L$ is open iff

\[\forall x \in O \exists a,b \in [L]. x \in (a,b) \wedge (a,b) \subset O\]

A neighbourhood of some point $x \in L$ is a set $U \subset L$ for which, for some $a,b \in [L]$, we have $x \in (a,b)$ and $(a,b) \subset U$.

For example, if $L = \ZZ$ with its usual order, then the order topology is the discrete topology (i.e. every set is open). For $n \in \ZZ$, we have that $(n-1,n+1) = \{n\}$, therefore for $O \subset \ZZ$, we have, for all $n \in O$, $(n-1,n+1) \subset O$. As another example, the order topology on $\overline{\NN} = \NN + \{\omega\}$ is compact (I use $\omega$ here so it doesn't get confused with the $\infty$ of $[\overline{\NN}]$). Given an open cover $\Sigma$, there must be some open $O \in \Sigma$ with $\omega \in O$. This open set $O$ includes a basic open set $(a,b)$ containing $\omega$, i.e. with $a < \omega$. However, if $a < \omega$, then $a = -\infty$ or $a \in \NN$. In case $a = -\infty$, $\{O\}$ is a finite subcover of $\Sigma_0$. If $a \in \NN$, then the set $\{n \in \NN \mid n \le a\}$ of points not covered by $B$ is finite, so we can choose (with finite choice) for each $n \le a$ some open $O_n \in \Sigma$ with $n \in O_n$. Then, $\{O_n \mid n \le a\} \cup \{O\}$ is a finite subcover of $\Sigma$.

In this chapter, we mainly focus on the order topology of $\alpha$ where $\alpha$ is an ordinal.

Limit Ordinals

We endow $\Ord$ with the order topology.

Every ordinal $\alpha$ has a direct successor $\alpha+1$: the embedding $\alpha \to \alpha+1$ that maps $\alpha$ to the left part of $\alpha+1$ is a proper segment, witnessing $\alpha \prec \alpha+1$. Not every ordinal has a direct predecessor. For example, the ordinal $0$ is the minimal ordinal, so there is no $\alpha < 0$. As another example, the ordinal $\omega = (\NN,<)$ has no direct predecessor, as every $n < \omega$ is finite and $n < n+1 < \omega$. We can partition $\Ord$ into three classes:

  • The class $\{0\}$ with only the ordinal $0$;
  • The class $\Succ$ of successor ordinals, i.e. ordinals of the form $\alpha+1$ for some ordinal $\alpha$;
  • The class $\Lim = \Ord'$ of limit ordinals.

There are a few equivalent definitions of a limit ordinal. An ordinal $\alpha \in \Ord$ is said to be a limit ordinal iff one of the following equivalent definitions holds:

  • The ordinal $\alpha$ is a limit point (in the topological sense) of $\Ord$;
  • The ordinal $\alpha$ is not zero and not a successor ordinal;
  • There is some $x < \alpha$ and, for all $x < \alpha$, we have $x+1 < \alpha$;
  • $\alpha$ is of the form $\omega\beta$ for some non-zero ordinal $\beta$;
  • $\alpha$ is of the form $\omega(1+\beta)$ for some ordinal $\beta$.

We can generalize the notion of a limit ordinal to a limit of a set of ordinals. For a set $A \subset \Ord$, its set of limits $A'$ is the set of ordinals $\alpha \in \Ord$ for which one of the following equivalent definitions holds:

  • The ordinal $\alpha$ is a limit point of $A$;
  • $\alpha$ is positive (i.e. not zero) and for all $x < \alpha$, there is some $y \in A$ for which $x < y < \alpha$.

For example, $\Succ' = \Lim$, and $\Lim'$ is the set of ordinals of the form $\omega^2\beta$ with positive $\beta$ (as you'll prove in the exercises).

If $\alpha \in A'$, then we say $A$ (sometimes $A \cap \alpha = \{\beta \in A \mid \beta < \alpha\}$) is unbounded in $\alpha$.

Open and Closed sets of Ordinals

In this part, we'll see what it means for a set $O \subset \Ord$ of ordinals to be open, and what it means for a set $C \subset \Ord$ of ordinal to be closed.

A set $O \subset \Ord$ of ordinals is open iff, for all limit ordinals $\lambda \in O$, there is some ordinal $\alpha < \lambda$ for which $(\alpha,\lambda) \subset O$.

A set $C \subset \Ord$ of ordinals is closed iff $C' \subset C$, where $C'$ is the set of limit points of $C$. A set $C \subset \alpha$ of ordinals below $\alpha$ is closed in $\alpha$ iff $C' \cap \alpha \subset \alpha$, where $C' \cap \alpha$ is the set of limit points of $C$ that are below $\alpha$.

Another important kind of set is a club set. A set $C \subset \alpha$ is club (in $\alpha$) iff $C$ is closed and unbounded. Club sets are used in the definition of a stationary set, which we'll see in a later chapter.

Cofinality, Initial and Regular Ordinals

A set $C \subset \alpha$ of ordinals below $\alpha$ is said to be cofinal (in $\alpha$) iff:

\[\forall a < \alpha \exists b \in C. a \le b\]

Equivalently,

  • If $\alpha = 0$, then $C = \varnothing$;
  • If $\alpha = \beta+1$ is a successor ordinal, then $\beta \in C$;
  • If $\alpha$ is a limit ordinal, then $C$ is unbounded.

An embedding $f: \beta \to \alpha$ is said to be cofinal iff the image $\im f$ of $f$ is cofinal in $\alpha$, equivalently:

\[\forall a < \alpha \exists b < \beta a \le f(b)\]

Note there is a bijection between cofinal subsets of $\alpha$ and cofinal embeddings into $\alpha$: every embedding $f: \beta \to \alpha$ corresponds to the cofinal subset $\im f$, and the ordering $(C,<)$ of every cofinal subset $C$ is isomorphic with an ordinal $\beta$, of which the isomorphism $f: \beta \to C$ can be compossed with the inclusion $i: C \to \alpha$ to get a cofinal embedding $f: \beta \to \alpha$.

For a set $A$ of ordinals, we call the ordinal $\alpha$ with which $A$ is isomorphic the order type of $A$, denoted $\otyp(A)$. We then have an embedding $f: \otyp(A) \to \Ord$ with image $\im f = A$, this embedding is called the enumeration of $A$.

The cofinality of an ordinal $\alpha$ is the smallest ordinal $\beta$ for which there is a cofinal embedding $f: \beta \to \alpha$. We denote the cofinality of $\alpha$ as $\cf(\alpha)$. Note that $\cf(\alpha)$ exists as the set of ordinals $\beta$ with a cofinal embedding $\beta \to \alpha$ is non-empty (it contains $\alpha$, witnessed by the embedding $\id_{\alpha}$), and therefore, as $\Ord$ is well-ordered, it has a minimal element. We call an ordinal $\alpha$ regular iff $\cf(\alpha) = \alpha$. The cofinality operation $\cf: \Ord \to \Ord$ is idempotent, meaning that $\cf(\alpha)$ is regular for any ordinal $\alpha$.

An ordinal $\alpha = (A,<)$ is initial iff for all $\beta < \alpha$, where $\beta = (B,<)$, we have $|B| < |A|$. Examples of initial ordinals are the finite ordinals, and the ordinal $\omega$. A non-example is the ordinal $\omega+1$, as $|\omega+1| = |\omega| = \aleph_0$, and therefore $|\omega| \not < |\oemga+1|$. All regular ordinals are initial, as you will verify in the exercises. For this reason, the cofinality of an ordinal may sometimes refer to the cardinality of $\cf(\alpha)$: we have $|\cf(\alpha)| = |\cf(\beta)|$ iff $\cf(\alpha) = \cf(\beta)$. Here, the cardinality of an ordinal $\alpha = (A,<)$ is defined as the cardinality of its underlying set $A$.

The fibres of $\cf$ refine the partition of $\Ord$ made in the part Limit Ordinals.

  • $\cf(\alpha) = 0$ iff $\alpha = 0$;
  • $\cf(\alpha) = 1$ iff $\alpha$ is a successor ordinal;
  • $\cf(\alpha) \ge \omega$ iff $\alpha$ is a limit ordinal.

$\omega_1$

The ordinal $\omega_1$ is the smallest uncountable ordinal. All ordinals below $\omega_1$ are countable, and all ordinals above $\omega_1$ are uncountable. Of course, there is the question of whether we can construct an uncountable well-order. And yes, we can. Let

\[B = \sum_{S \subset \NN} S \times S\]

be the set of pairs $(S,R)$ with $S$ a subset of $\NN$ and $R$ a binary relation on $S$, and let $W \subset B$ be the subset of well-orders. Then, we can define an equivalence relation

\[(S,R) \sim (S',R') \iff \exists f: S \leftrightarrow S' \forall a,b \in S. a R b \Leftrightarrow f(a) R' f(b)\]

on $W$ and take the quotient $Q = W/\sim$. Then, we can define a well-order $<$ on $Q$ as follows: $[S,R] < [S',R']$ iff $(S,R) < (S',R')$ as ordinals. Then, $(Q,<) is the minimal uncountable well-order.

$\omega_1$ is an initial ordinal: every $\alpha < \omega_1$ is countable, and therefore $|\alpha| \le \aleph_0 < |\omega_1|$. It is the smallest initial ordinal greater than $\omega$. The cardinality of $\omega_1$ is $\aleph_1$, or Aleph-one. Surprisingly, the ordinal $\omega_1$ does not need to be regular. In the Feferman-Levy model, we in fact have $\cf(\omega_1) = \omega$. Assuming the axiom of choice, the ordinal $\omega_1$ is regular. Here is a short proof of this fact:

Let $C \subset \omega_1$ be cofinal and assume, towards contradiction, $C$ is countable. Let $f: C \hookrightarrow \NN$ be an injection. For each ordinal $\alpha \in C$, choose an injection $g_{\alpha}: \alpha \hookrightarrow \NN$. Define an injection $h: \omega_1 \hookrightarrow \NN \times \NN$ as follows: for each ordinal $\beta < \omega_1$, let $\alpha \in C$ be minimal with $\beta < \alpha$ (which exists as $C$ is unbounded in $\omega_1$), and set $h(\beta) := (f(\alpha),f_{\alpha}(\beta)). The injection $h: \omega_1 \hookrightarrow \NN \times \NN$ witnesses $|\omega_1| \le |\NN \times \NN| = \aleph_0$, i.e. $\omega_1$ is countable. However, $\omega_1$ is, by definition, uncountable.

The axiom of choice was needed in the proof above the choose the injections $g_{\alpha}$. Only a small fragment of choice is needed to show $\omega_1$ is regular, known as the countable union theorem, or CUT, which states that a union of countably many countable sets is countable.

U \cap A \neq \varnothing\} \\ \partial A &=& \{a \in A \mid \forall U \ni a. U \cap A \neq \varnothing \wedge U \setminus A \neq \varnothing\} \end{array}\]

In the order-topology of the reals $\RR$, for each of the following, prove or give a counter-example:

  • For all sets $A \subset \RR$, $\partial A = A$;
  • For all sets $A \subset \RR$, $\partial \partial A = \partial A$;
  • For all sets $A \subset \RR$, $\partial \partial \partial A = \partial \partial A$.

where $\Ord^+ = \Ord \smallsetminus 0$ is the set of positive ordinals.
