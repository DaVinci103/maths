Overview of Algebraic Structures

Preliminaries

Given a set $A$, we write $x \in A$ for the proposition "$x$ is an element of $A$". We write $x = y$ to denote two elements $x,y \in A$ are equal. Every element is equal to itself (reflexivity), and equal elements are interchangable (J-rule). For example, if $x = y$, then, as $x = x$ (by reflexivity), we may swap the first $x$ with $y$, and we get $y = x$ (by the J-rule). This consequence is known as symmetry of $=$. If $x = y$ and $y = z$, then we can replace $y$ in $x = y$ with $z$ (by the J-rule), and therefore $x = z$. This consequence is called transitivity of $=$.

Some examples of sets are: the empty set, $\varnothing$, which contains no elements. The singleton $1$, which contains a single element $*$ (i.e. for all $x \in 1$, we have $x = *$). For any number of elements $x_1,\ldots,x_n$, we write $\{x_1,\ldots,x_n\}$ for the set containing all and only those elements. For example, $1 = \{*\}$. For a natural number $n$, we write $n$ for the set $\{0_n,\ldots,(n-1)_n\}$ of $n$ elements. For example, $2 = \{0_2,1_2\}$ and $4 = \{0_4,1_4,2_4,3_4\}$. We sometimes omit the subscripts for brevity and simply write $4 = \{0,1,2,3\}$. Elements of $2$ are also sometimes called "false" ($=0_2$) and "true" ($=1_2$). The set $\NN$ is the set of natural numbers $\{0,1,2,3,4,\ldots\}$.

For sets $A$ and $B$, a function $f: A \to B$ has the following data and conditions:

  • Totality. To each element $x$ of $A$, an associated element $f(x)$ of $B$;
  • Functionality. For any two elements $x$ and $y$, if $x = y$, then $f(x) = f(y)$.

Functionality is technically a consequence of the J-rule, though it's important enough to mention separately. We sometimes write $fx$ for $f(x)$ for brevity. In the notation $f(x)$, we call $x$ the argument of $f$ and $f(x)$ the value of $f$ at $x$. The set $A$ is called the domain of the function $f$, and $B$ is the codomain. We call $f$ a function from $A$ to $B$.

For example, every set $A$ has an identity function $\id: A \to A$ that associates, to each element $a$ of $A$, that same element $\id(a) = a$. And, for any two sets $A$ and $B$ and any element $b$ of $B$, we there is a constant function $\const_b: A \to B$ that associates, to each element $a$ of $A$, the same element $\const_b(a) = b$ of $B$. For every set $A$, there is a unique function $\varnothing \to A$. As there are no elements of $\varnothing$, there are no arguments to which we need to associative values. This function is called the empty function of $A$. Similarly, for any set $A$, there is a unique function $A \to 1$ that maps every element $A$ to the unique element $*$ of $1$.

Given sets $A$ and $B$, we can define a new set $[A,B]$ of all functions from $A$ to $B$. Alternative notations of $[A,B]$ are $B^A$, ${}^AB$ and $A \Rightarrow B$. Elements $f,g \in [A,B]$ are equal iff, for all $x \in A$, we have $f(x) = g(x)$.

For sets $A$ and $B$, we define a new set $A \times B$. For every element $a$ of $A$ and every element $b$ of $B$, $(a,b)$ is an element of $A \times B$ and is called a pair. Further, if $(a,b) = (c,d)$, then $a = c$ and $b = d$. Any element $p$ of $A \times B$ is a pair $(a,b)$ for some $a \in A$ and some $b \in B$. In this case, we write $p_0$ for $a$ and $p_1$ for $b$. So that: $(p_0,p_1) = p$, $(a,b)_0 = a$ and $(a,b)_1 = b$. We write $\pi_0: A \times B \to A$ and $\pi_1: A \times B \to B$ for the functions that associative to each element $(a,b)$ of $A \times B$, the element $a$ of $A$ and the element $b$ of $B$ respectively. The functions $\pi_0,\pi_1$ are called the projection functions of $A \times B$.

A (binary) operation on $A$ is a function $\star: A \times A \to A$. We write $a \star b$ for $\star(a,b)$. Whether to calculate $a \star b \star c$ as $(a \star b) \star c$ or $a \star (b \star c)$ is called the associativity of the notation for $\star$, and is specified for each operation that is introduced separately. In the former case, the notation for $\star$ is left-associative, and in the latter case, the notation for $\star$ is right-associative. For two operations $\star$ and $\circ$ on the same set $A$, whether to calculate $\star$ first or $\circ$ first in an expression in which both occur, such as $a \star b \circ c \star d$, is called the precedence of the notation. If $\star$ is calculated first, i.e. $a \star b \circ c \star d$ is interpreted as $(a \star b) \circ (c \star d)$, then we say $\star$ has higher precedence than $\circ$. Symmetrically, if $\circ$ is calculated first, i.e. $a \star b \circ c \star d$ is interpreted as $a \star (b \circ c) \star d$ (which is $(a \star (b \circ c)) \star d$ or $a \star ((b \circ c) \star d)$ depending on the associativity of the notation for $\star$), then $\star$ has lower precedence than $\circ$. If they have the same precedence, then there associativity must align. E.g. say the notation for $\star$ and $\circ$ are left-associative. Then, $a \star b \circ c \star d$ is interpreted as $((a \star b) \circ c) \star d$. If the symbol $\cdot$ is used for an operation, then we may also write $a \cdot b$ using juxtaposition, i.e. as $ab$. Juxtaposition has precedence above all operators so that, for example, $ab \cdot c$ is interpreted as $(a \cdot b) \cdot c$, and $a \cdot bc$ is interpreted as $a \cdot (b \cdot c)$. Hopefully, you already know examples of this: the four operations $+$, $-$, $\times$ and $\div$ on the reals are all left-associative, $+$ and $-$ have the same precedence, so do $\times$ and $\div$, and $\times$ and $\div$ have higher precedence than $+$ and $-$. Note: $\div$ is technically not an operation as division by $0$ is not possible, but we can simply define $a \div 0$ to have a dummy value, such as $0$, to make it one.

We write $\forall$ and $\exists$ for for all and there exists. For example, $(\forall b \in B) \, (\exists a \in A) \, f(a) = b$ means for all $b$ in $B$, there exists an $a$ in $A$ for which $f(a) = b$.

Conditions

Fix a set $A$ and a binary operations $\star$ and $\circ$ on $A$. We define various conditions these operations can have.

The operation $\star$ is associative iff $(\forall a\,b\,c \in A) \, (a \star b) \star c = a \star (b \star c)$. In this case, it doesn't matter if the notation for $\star$ is left- or right-associative. Examples of associative operations are $+$ and $\times$. A non-example is $-$, as $(11 - 6) - 2 = 5 - 2 = 3 \neq 11 - (6 - 2) = 11 - 4 = 7$.

Elements $a$ and $b$ of $A$ are said to commute with respect to the operation $\star$ iff $a \star b = b \star a$. The operation $\star$ is called commutative, or symmetric, iff $(\forall a\,b \in A) \, a \star b = b \star a$, i.e. if any two elements of $A$ commute. For example, $+$ and $\times$ are symmetric, while $-$ and $\div$ are not.

An element $e$ of $A$ is a left-identity for the operation $\star$ iff $(\forall a \in A) \, e \star a = a$. It is a right-identity iff $(\forall a \in A) \, a \star e = a$. It is an identity iff it is both a left- and a right-identity. For example, $0$ is an identity for $+$ and a right-identity for $-$, and $1$ is an identity for $\times$. Note that, if $e_1$ is a right-identity, and $e_2$ is a left-identity, then $e_1 = e_1 \star e_2 = e_2$. Hence, the identity of $\star$, if it exists, is unique.

An element $z$ of $A$ is an absorption element iff $(\forall a \in A) \, z \star a = a \star z = z$. We define left- and right-absorption elements analogously to identity elements. For example, $0$ is an absorption element for $\times$.

For an identity $e$ for $\star$, an element $b \in A$ is a left-inverse of an element $a \in A$ iff $b \star a = e$. The element $b$ is a right-inverse of $a$ iff $a \star b = e$ and an inverse of $a$ iff it is both a left- and right-inverse. If every element has an inverse, then we say $\star$ has inverses. Note $\star$ must have an identity element for it to have inverses.

The operation $\circ$ is left-distributive over $\star$ iff $(\forall a\,b\,c \in A) \, a \circ (b \star c) = (a \circ b) \star (a \circ c)$. It is right-distributive iff $(\forall a\,b\,c \in A) (a \star b) \circ c = (a \circ c) \star (b \circ c)$ and it is distributive, or distributes over $\star$, iff it is both left- and right-distributive. For example, $\times$ distributes over $+$: $a \times (b + c) = a \times b + a \times c$, and $(a + b) \times c = a \times c + b \times c$.

Algebraic Structures

A pair $(A,\star)$ with a set $A$ and a binary operation $\star$ on $A$ is called a magma. There are different kinds of magmas.

A semigroup is a magma with an associative operation. A unital magma is a magma with an identity element. A monoid is a semigroup and a unital magma. A loop is a unital magma that has left- and right-inverses (that don't need to be equal). A group is a monoid that has inverses. An Abelian group, or commutative group, is a group with a commutative operation. We'll focus mostly on groups and Abelian groups.

We may have a triple $(A,\star,\circ)$ with a set $A$ and two binary operations $\star$ and $\circ$ on $A$. Such a triple is a:

Ring iff $(A,\star)$ is an Abelian group, $(A,\circ)$ is a monoid and $\circ$ distributes over $\star$. Commutative ring, or cring (capitalized: CRing) iff it is a ring and $\circ$ is commutative. Division ring iff it is a ring and every element, except for the identity element of $\star$, has an inverse with respect to $\circ$. Field iff it is a division cring.

Examples of rings are the ring $(\ZZ,+,\cdot)$ of integers, the ring $(\QQ,+,\cdot)$ of rational numbers and the ring $(\RR,+,\cdot)$ of real numbers. These are all also commutative, and the latter example is also a field. Non-examples are the even integers $(2\ZZ,+,\cdot)$, as there is no multiplicative identity (identity for $\cdot$), and the natural numbers $(\NN,+,\cdot)$, as there are no negatives (inverses for $+$). These are a rng (pronounced: rung) and a rig respectively.

Typically, the operation of a group is denoted $\cdot$ and the operation of an Abelian group is denoted $+$. We write the first and second operation of a ring as $+$ and $\cdot$ respectively. We typically write $0$ for the identity of any operation denoted $+$ and $1$ for the identity of any operation denoted $\cdot$. If inverses for $+$ or $\cdot$ are unique (e.g. if they are associative as part of a ring), then we write $-a$ for the inverse of an element $a$ with respect to $+$ and $a^{-1}$ for the inverse of $a$ with respect to $\cdot$, provided those inverses exist. Another important kind of ring is an integral domain. A ring $(R,+,\cdot)$ is an integral domain iff $(\forall a\,b \in R) a \cdot b = 0 \implies a = 0 \vee b = 0$. here, $\implies$ means implies and $\vee$ means or, and $\vee$ has higher precedence than $\implies$. So this reads For all elements $a$ and $b$ of $R$, if $a \cdot b = 0$, then $a = 0$ or $b = 0$.

Modules

let $(M,\cdot)$ be a monoid and let $X$ be a set. Let $\star: M \times X \to X$ be a function and write $m \star x$ for $\star(m,x)$. We call $\star$ an action of $(M,\cdot)$ on $X$ iff:

  • For the identity element $e$ of $M$, $(\forall x \in X) \, e \cdot x = x$;
  • $(\forall m\,n \in M, x \in X) \, m \star (n \star x) = (m \cdot n) \star x$.

This definition applies to groups as well. We write $\star: (M,\cdot) \curvearrowright X$ for $\star$ is an action of $(M,\cdot)$ on $X$.

Given a ring $(R,+,\cdot)$, an $R$-module is a triple $(M,\star,\circ)$ where $(M,\star)$ is an Abelian group and $\circ: (R,\cdot) \curvearrowright M$ is an action satisfying:

  • $(\forall r \in R, m\,n \in M) \, r \circ (m \star n) = (r \circ m) \star (r \circ n)$;
  • $(\forall r\,s \in R, m \in M) \, (r + s) \circ m = (r \circ m) \star (s \circ m)$.

We typically write $+$ for $\star$ and $\cdot$ for $\circ$. These functions shouldn't be confused with the operations $+$ and $\cdot$ of the ring. In the case the ring $(R,+,\cdot)$ is a field, we sometimes call an $R$-module an $R$-vector space.
