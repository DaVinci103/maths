Groupoids and Categories

Groupoids

Suppose we have sets $3 = \{0_3,1_3,2_3\}$ and $S = \{\triangle,\square\}$. These sets are clearly distinct: $3$ contains three elements, while $S$ contains two. So, for example, the sentence $(\forall a\,b\,c \in A) \, a=b \vee b=c \vee a=c$ would be true for $A = S$ but false for $A = 3$. Now consider the sets $2 = \{0_1,0_2\}$ and $S = \{\triangle,\square\}$. At first glance, it might seem that these two sets are still distinct: they contain different elements. But what does "different" mean here really? We cannot ask whether elements of different sets are equal: the identity relation is defined within a set. We have given the elements different symbols, but whether you use 4 to refer to the real number four or IV, it doesn't change the fact that it is the number four. For any sentence we could think of, for example the sentence $(\exists a \in A) \, a = a$, either it is true for both $A = 2$ and $A = S$, or neither $A = 2$ or $A = S$. So, saying that $2$ and $S$ are different sets seems to be not entirely correct. On the other hand, if $2$ and $S$ are merely equal, we would get that $(\forall a \in 2) \, (\exists b \in S) \, a = b$ (this holds when replacing $S$ with $2$, and equal elements (in this case, sets) are interchangable), but would $0_2$ equal $\triangle$ and $1_2$ equal $\square$, or would $1_2$ equal $\triangle$ and $0_2$ equal $\triangle$? There doesn't seem to be a clear answer to this, so saying that $2$ and $S$ are merely equal also seems to be not entirely correct.

This paradox can be resolved as follows: instead of saying two sets $A$ and $B$ are either merely equal or not equal, we say that for any two sets $A$ and $B$ there is a set of identifications $\Id(A,B)$. If $A$ and $B$ are equal, then the set of identifications $\Id(A,B)$ has at least one element, and if $A$ and $B$ are not equal, then the set of identifications is empty. In the example above, the set of identifications $\Id(2,S)$ has two elements. One identifies $0_2$ with $\triangle$ and $1_2$ with $\square$, and the other identifies $0_2$ with $\square$ and $1_2$ with $\triangle$. So, sets seem to live in a collection in which any two elements have a set of identifications. Such a collection is called a groupoid.

A groupoid is a collection $A$. We write $a \in A$ for $a$ is an element of the groupoid $A$. For elements $a$ and $b$ of $A$, there is a set $\Id_A(a,b)$ called the set of identifications of $a$ and $b$. We write $p \in \Id_A(a,b)$, $p: a = b$ or $p: a \rightsquigarrow b$ to denote $p$ is an identification of $a$ with $b$, sometimes referred to as a path from $a$ to $b$. For any element $a \in A$, there is an identification $\rfl_a \in \Id_A(a,a)$ called reflexivity. Further, to prove or construct something for any path from a given element $a$, it is sufficient to prove or construct it for the path $\rfl_a$ (this is called the J-rule of groupoids).

The J-rule might be a bit confusing for groupoids, so let's look at some examples.

Suppose we have a path $p: a \rightsquigarrow b$ and we want to construct a path $p^{-1}: b \rightsquigarrow a$ in the other direction. As we want to construct something for any path from $a$, it is sufficient to define it for the path $\rfl_a: a \rightsquigarrow a$. We can define the path $\rfl_a^{-1}: a \rightsquigarrow a$ going in the other direction by $\rfl_a^{-1} := \rfl_a$. This completes the construction. The path $p^{-1}$ is called the inverse of $p$ and acts as the groupoid's symetry law.

As another example, suppose we have a path $p: a \rightsquigarrow b$ and a path $q: b \rightsquigarrow c$ and we want to construct a path $q \cdot p: a \rightsquigarrow c$. As we want to define something for any path $p$ out of $a$, it is sufficient to define it for the path $\rfl_a: a \rightsquigarrow a$. In this case, we have a path $q: a \rightsquigarrow c$ and we want to define a path $q \cdot \rfl_a: a \rightsquigarrow c$. We can define this path by $q \cdot \rfl_a := q$. The path $q \cdot p$ is called the concatenation of $p$ and $q$. It acts as the groupoid's transitivity law.

As for a non-example, suppose we want to prove, for any path $p: a \rightsquigarrow a$, that $p = \rfl_a$. The following argument does not work:

As we want to prove something for any path $p: a \rightsquigarrow a$, it is sufficient to prove it for the path $\rfl_a: a \rightsquigarrow a$. As $\rfl_a$ belongs to the set $\Id_A(a,a)$, and the identity relation on sets is reflexive, we have $\rfl_a = \rfl_a$. This completes the proof.

The flaw in the argument might be hard to spot. In the argument above, we didn't want to prove something for every path out of $a$, but only for every path $p: a \rightsquigarrow a$. If we considered every path $p: a \rightsquigarrow b$, then the sentence "$p$ is equal to $\rfl_a$" doesn't make sense anymore: $p$ belongs to the set $\Id_A(a,b)$, and $\rfl_a$ belongs to the set $\Id_A(a,a)$. Though these two sets are equal, we do need an identification of these sets to treat elements of one set as elements of the other, and there is no identification that works here.

It turns out it is not possible to prove any identification in $\Id_A(a,a)$ is equal to $\rfl_a$. To give an example for where this isn't the case, consider the set $\Id(2,2)$ of identifications of the set $2$ with itself. There is an identification $\rfl_2$, which identifies $0_2$ with $0_2$ and $1_2$ with $1_2$, but there also is an identification $\neg$, which identifies $0_2$ with $1_2$ and $1_2$ with $0_2$.
