Groupoids and Categories

Groupoids

Suppose we have sets $3 = \{0_3,1_3,2_3\}$ and $S = \{\triangle,\square\}$. These sets are clearly distinct: $3$ contains three elements, while $S$ contains two. So, for example, the sentence $(\forall a\,b\,c \in A) \, a=b \vee b=c \vee a=c$ would be true for $A = S$ but false for $A = 3$. Now consider the sets $2 = \{0_1,0_2\}$ and $S = \{\triangle,\square\}$. At first glance, it might seem that these two sets are still distinct: they contain different elements. But what does "different" mean here? We cannot ask whether elements of different sets are equal: the identity relation is defined within a set. We have given the elements different symbols, but whether you use 4 to refer to the real number four or IV, it doesn't change the fact that it's the real number four. For any sentence we could think of, for example the sentence $(\exists a \in A) \, a = a$, either it is true for both $A = 2$ and $A = S$, or neither $A = 2$ or $A = S$. So, saying that $2$ and $S$ are different sets seems to be not entirely correct. On the other hand, if $2$ and $S$ are merely equal, we would get that $(\forall a \in 2) \, (\exists b \in S) \, a = b$ (this holds when replacing $S$ with $2$, and equal elements (in this case, sets) are interchangable), but would $0_2$ equal $\triangle$ and $1_2$ equal $\square$, or would $1_2$ equal $\triangle$ and $0_2$ equal $\triangle$? There doesn't seem to be a clear answer to this, so saying that $2$ and $S$ are merely equal also seems to be incorrect, or at least this answer is incomplete.

This paradox can be resolved as follows: instead of saying two sets $A$ and $B$ are either merely equal or not equal, we say that for any two sets $A$ and $B$ there is a set of identifications $\Id_{\Set}(A,B)$. If $A$ and $B$ are equal, then the set of identifications $\Id_{\Set}(A,B)$ has at least one element, and if $A$ and $B$ are not equal, then the set of identifications is empty. In the example above, the set of identifications $\Id_{\Set}(2,S)$ has two elements. One identifies $0_2$ with $\triangle$ and $1_2$ with $\square$, and the other identifies $0_2$ with $\square$ and $1_2$ with $\triangle$. So, sets seem to live in a collection in which any two elements have a set of identifications. Such a collection is called a groupoid.

A groupoid is a collection $A$. We write $a \in A$ for $a$ is an element of the groupoid $A$. For elements $a$ and $b$ of $A$, there is a set $\Id_A(a,b)$ called the set of identifications of $a$ and $b$. We write $p \in \Id_A(a,b)$, $p: a = b$ or $p: a \rightsquigarrow b$ to denote $p$ is an identification of $a$ with $b$, sometimes referred to as a path from $a$ to $b$. For any element $a \in A$, there is an identification $\rfl_a \in \Id_A(a,a)$ called reflexivity. Further, to prove or construct something for any path from a given element $a$, it is sufficient to prove or construct it for the path $\rfl_a$ (this is called the J-rule of groupoids).

The J-rule might be a bit confusing for groupoids, so let's look at some examples.

Suppose we have a path $p: a \rightsquigarrow b$ and we want to construct a path $p^{-1}: b \rightsquigarrow a$ in the other direction. As we want to construct something for any path from $a$, it is sufficient to define it for the path $\rfl_a: a \rightsquigarrow a$. We can define the path $\rfl_a^{-1}: a \rightsquigarrow a$ going in the other direction by $\rfl_a^{-1} := \rfl_a$. This completes the construction. The path $p^{-1}$ is called the inverse of $p$ and acts as the groupoid's symetry law.

As another example, suppose we have a path $p: a \rightsquigarrow b$ and a path $q: b \rightsquigarrow c$ and we want to construct a path $q \cdot p: a \rightsquigarrow c$. As we want to define something for any path $p$ out of $a$, it is sufficient to define it for the path $\rfl_a: a \rightsquigarrow a$. In this case, we have a path $q: a \rightsquigarrow c$ and we want to define a path $q \cdot \rfl_a: a \rightsquigarrow c$. We can define this path by $q \cdot \rfl_a := q$. The path $q \cdot p$ is called the concatenation of $p$ and $q$. It acts as the groupoid's transitivity law.

As for a non-example, suppose we want to prove, for any path $p: a \rightsquigarrow a$, that $p = \rfl_a$. The following argument does not work:

As we want to prove something for any path $p: a \rightsquigarrow a$, it is sufficient to prove it for the path $\rfl_a: a \rightsquigarrow a$. As $\rfl_a$ belongs to the set $\Id_A(a,a)$, and the identity relation on sets is reflexive, we have $\rfl_a = \rfl_a$. This completes the proof.

The flaw in the argument might be hard to spot. In the argument above, we didn't want to prove something for every path out of $a$, but only for every path $p: a \rightsquigarrow a$. If we considered every path $p: a \rightsquigarrow b$, then the sentence "$p$ is equal to $\rfl_a$" doesn't make sense anymore: $p$ belongs to the set $\Id_A(a,b)$, and $\rfl_a$ belongs to the set $\Id_A(a,a)$. Though these two sets are equal, we do need an identification of these sets to treat elements of one set as elements of the other, and there is no identification that works here. More fundamentally, the flaw in the proof above is that the end-point of a path $p: a \rightsquigarrow a$ isn't free: it must be $a$. The J-rule may only be applied on paths for which the end-point is free. I.e. paths $p: a \rightsquigarrow b$ where $b$ is independent of $a$.

It turns out it is not possible to prove any identification in $\Id_A(a,a)$ is equal to $\rfl_a$. To give an example for where this isn't the case, consider the set $\Id_{\Set}(2,2)$ of identifications of the set $2$ with itself. There is an identification $\rfl_2$, which identifies $0_2$ with $0_2$ and $1_2$ with $1_2$, but there also is an identification $\neg$, which identifies $0_2$ with $1_2$ and $1_2$ with $0_2$.

I want to give a few more important application of the J-rule. First, suppose we have paths $a \overset{p}{\rightsquigarrow} b \overset{q}{\rightsquigarrow} c \overset{r}{\rightsquigarrow} d$. Consider the two paths $(r \cdot q) \cdot p$ and $r \cdot (q \cdot p)$ from $a$ to $d$. We can prove these two paths are equal. As the end-points of $p,q,r$ are all free, we can apply the J-rule to all of them to simplify the situation to $a \overset{\rfl_a}{\rightsquigarrow} a \overset{\rfl_a}{\rightsquigarrow} a \overset{\rfl_a}{\rightsquigarrow} a$, and we want to prove $(\rfl_a \cdot \rfl_a) \cdot \rfl_a = \rfl_a \cdot (\rfl_a \cdot \rfl_a)$. As we have defined $q \cdot \rfl_a := q$, both expressions simplify to $\rfl_a$. So, we want to prove $\rfl_a = \rfl_a$, which is immediate from reflexivity of the identity relation on sets. This means that path concatenation is associative. Second, suppose we have a path $p: a \rightsquigarrow b$. We want to prove $p^{-1} \cdot p = \rfl_a$ and $p \cdot p^{-1} = \rfl_b$. We again apply the J-rule and the definition of path concatenation and path inversion to simplify both these equations to $\rfl_a = \rfl_a$ which is again immediate from reflexivity of the identity relation on the set $\Id_A(a,a)$. This means that $p^{-1}$ is an inverse for $p$ with respect to path concatenation. Last, given a path $p: a \rightsquigarrow b$, we can prove $\rfl_b \cdot p = p$ in again the same way. As we have $q \cdot \rfl_a = q$ by definition, this means that $\rfl_a$ is an identity element for path concatenation.

Note that, as the proof above applies to all paths, in particular, it applies to loops, i.e. paths from $a$ to $a$ for some $a$. We have proven $(\Id_A(a,a),\cdot)$ is a group, with identity element $\rfl_a$ and inverses given by path inversion. Note that we could only prove $(\Id_A(a,a),\cdot)$ is a group because we could prove (and, importantly, state) the equations of a group for paths with free end-points. We could only prove $(r \cdot q) \cdot p = r \cdot (q \cdot p)$ for any three loops $p\,q\,r: a \rightsquigarrow a$ because we could prove it for any three paths. We couldn't prove $p = \rfl_a$ for any loop $p$ because we couldn't prove, or even state it for any path $p$. One of the main reasons we study groups is because they arise naturally like this as a structure containing the ways in which an object is equal to itself (what we here call identifications of an object with itself are within the context of group theory called symmetries of that object).

Now that we have defined groupoids, we want to formally define the groupoid of sets $\Set$. But first, a bit more background on sets:

Suppose we have sets $A$ and $B$ and a function $f: A \to B$. We call this function a surjection, denoted $f: A \twoheadrightarrow B$, iff $(\forall b \in B) \, (\exists a \in A) \, f(a) = b$. I.e. if every element of $B$ is mapped onto by at least one element of $A$. We call $f$ an injection, denoted by $f: A \hookrightarrow B$, iff $(\forall a\,b \in A) \, f(a) = f(b) \implies a = b$. I.e. if arguments of the function can be discerned from the function values, or if every element of $B$ is mapped onto by at most one element of $A$. We call $f$ a bijection, denoted $f: A \similarrightarrow B$, iff it is both an injection and a surjection. I.e. if every element of $B$ is mapped onto by $f$ exactly once. Further, suppose we have sets $A$, $B$ and $C$ and functions $f: A \to B$ and $g: B \to C$. We define a function $g \circ f: A \to C$, called the composition of $f$ and $g$, by $(g \circ f)(a) := g(f(a))$ for $a \in A$. Then, $f: A \to B$ is a bijection iff there exists a function $g: B \to A$ for which $g \circ f = \id_A$ and $f \circ g = \id_B$. In which case, $g$ is unique, is called the inverse of $f$ and is denoted $f^{-1}$. I recommend doing the exercises in Sets and Functions from the section Elementary Set Theory.

We write $\Bi(A,B)$ for the set of bijections from $A$ to $B$. In the groupoid of sets $\Set$, elements are sets. For sets $A$ and $B$, using the J-rule, we define a function $e_{A,B}: \Id_{\Set}(A,B) \to \Bi(A,B)$ by setting $e_{A,A}(\rfl_A) := \id_A$. We assume $e_{A,B}$ is a bijection. In other words, an identification of a set $A$ with a set $B$ is a bijection from $A$ to $B$.

I won't go into the details, but with the J-rule, we can prove that $e_{A,C}(q \cdot p) = e_{B,C}(q) \circ e_{A,B}(p)$ and $e_{B,A}(p^{-1}) = e_{A,B}(p)^{-1}$ for $p: A \rightsquigarrow B$ and $q: B \rightsquigarrow C$.

Every set $X$ is a groupoid in which any two elements of $\Id_X(a,b)$ are equal, for any $a,b \in X$. I.e. if $\Id_X(a,b)$ is always either empty or a singleton (has exactly 0 or 1 elements). So, anything that we define for groupoids can also be applied to sets. Sets and groupoids belong to a more general collection of types. A type is a collection $A$ for which, for all $x,y \in A$, there is a type of identifications $\Id_A(x,y)$. Sets and groupoids are then a particular kind of type. A set is also called a 0-type and a groupoid is a 1-type. Generally, an $n+1$-type is a type $A$ for which, for all $a,b \in A$, $\Id_A(a,b)$ is an $n$-type. We won't use types in this section beyond 1-types. If you're interested in the study of types, I recommend searching for Homotopy Type Theory.

If groupoids are still a bit too abstract to understand, one may replace every mention of a groupoid with a pregroupoid. A pregroupoid has the following data and conditions:

  • A set $A$ called the domain;
  • A function $\Idt: A \times A \to \Set$ that takes two elements $a,b \in A$ and returns a set $\Idt(a,b)$;
  • For any three elements $a,b,c \in A$ and any $p \in \Idt(a,b)$ and $q \in \Idt(b,c)$, we have some $q \dott p \in \Idt(a,c)$, $p \invt \in \Idt(b,a)$ and $\idt_a \in \Idt(a,a)$;
  • For any four elements $a,b,c,d \in A$ and any $p \in \Idt(a,b)$, $q \in \Idt(b,c)$ and $r \in \Idt(c,d)$, we have $(r \dott q) \dott p = r \dott (q \dott p)$, $p \invt \dott p = \idt_a$ and $p \dott p \invt = \idt_b$.

Note that $p \in \Idt(a,b)$ does not imply $a = b$ in $A$. The data of a pregroupoid mimicks that of a groupoid, but the rules of transitivity, symmetry, associativity and inverses are explicit in the definition instead of consequences of the J-rule.

There's still the issue of size to deal with. Given a groupoid $G$, we can define its set-trunctation $\|G\|_0$, which is a set with the same elements as $G$, and where $a = b$ holds in $\|G\|_0$ iff $\Id_G(a,b)$ has an element. For example, $\|\Set\|_0$ is a set, usually denoted $\Card$. However, this creates a paradox. I won't prove this here, but for any set $A$, we can define a family of sets $B_a$ for $a \in A$ that are all distinct (if there is some identification $p: B_a = B_b$, then $a = b$). Therefore, for any set $A$, $A$ is smaller than $\Card$. Also, for any set $A$, we can define a set $\mathcal{P}(A)$ strictly larger than $A$. This implies that $\mathcal{P}(\Card)$ is simultaneously smaller than $\Card$ and strictly larger than $\Card$, a contradiction. We resolve this paradox with the notion of a universe:

A universe $\mathcal{U}$ is a collection of types closed under a certain list of operations. Given a universe $\mathcal{U}$, we can define a collection of sets $\Set_{\mathcal{U}}$ in $\mathcal{U}$. This collection is itself not in the universe $\mathcal{U}$, but is in the next universe $\mathcal{U}^+$. When going through the paradox above, we see that $\textsf{Card}_{\mathcal{U}}$ is larger than any element of $\textsf{Set}_{\mathcal{U}}$ and itself not in $\textsf{Set}_{\mathcal{U}}$, so we cannot argue $\Card_{\mathcal{U}}$ is larger than $\mathcal{P}(\textsf{Card}_{\mathcal{U}})$ and the argument of the paradox does not go through.

We fix a universe $\mathcal{U}$ and we write $\Set$, $\Card$, etc, for $\Set_{\mathcal{U}}$, $\Card_{\mathcal{U}}$, etc.

Categories

A category is to a groupoid what a monoid is to a group. A precategory $\cC$ has the following data and conditions:

  • A groupoid $\cC_0$ of objects. We write $A \in \cC$ for $A \in \cC_0$;
  • For any two objects $A,B \in \cC$, a set $\cC(A,B)$ of arrows, morphisms or homomorphisms. We write $f: A \to B$ for $f \in \cC(A,B)$;
  • For any two arrows $f: A \to B$ and $g: B \to C$, a composite arrow $g \circ h: A \to C$;
  • For any object $A \in \cC$, an identity arrow $\id_A: A \to A$;
  • For any arrow $f: A \to B$, we have $f \circ \id_A = f$ and $\id_B \circ f = f$;
  • For any three arrows $f: A \to B$, $g: B \to C$ and $h: C \to D$, we have $(h \circ g) \circ f = h \circ (g \circ f)$.

A set-precategory is a precategory $\cC$ where $\cC_0$ is a set. We sometimes write $\Ob(\cC)$ for $\cC_0$ and $\Hom_\cC(A,B)$ or $\Hom(A,B)$ for $\cC(A,B)$.

In a precategory $\cC$, an isomorphism from an object $A$ to an object $B$ is an arrow $f: A \to B$ for which there exists an arrow $g: B \to A$ for which $g \circ f = \id_A$ and $f \circ g = \id_B$. In which case, we write $f: A \similarrightarrow B$, we call $g$ the inverse of $f$ and write $g = f^{-1}$. We write $\Iso_{\cC}(A,B)$ or $\Iso(A,B)$ for the collection of isomorphisms between $A$ and $B$. Note that $\id_A$ is an isomorphism as it is its own inverse.

Using the J-rule, we define a function $e_{A,B}: \Id_{\cC_0}(A,B) \to \Iso_{\cC}(A,B)$ by $e_{A,A}(\rfl_A) := \id_A$. If, for any $A,B \in \cC_0$, $e_{A,B}$ is a bijection, then we call $\cC$ a category. Categories and set-precategories are mostly interchangable, just like groupoids and pregroupoids.

The prime example of a category is the category $\Set$ of sets. The underlying groupoid $\Set_0$ is the groupoid of sets. For sets $A,B \in \Set$, we define $\Set(A,B) := [A,B]$ to be the set of functions from $A$ to $B$. For functions $f: A \to B$ and $g: B \to C$, $g \circ f$ is the usual composition $(g \circ f)(a) = g(f(a))$ and $\id_A$ is the usual identity $\id_A(a) = a$. By definition, $\Iso_{\Set}(A,B) = \Bi(A,B)$. The function $e: \Id \to \Iso$ defined above is the same function as $e: \Id \to \Bi$ defined in the previous part, which we assumed to be bijective. So, $\Set$ is indeed a category as opposed to a precategory.
