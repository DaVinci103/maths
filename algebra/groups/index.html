Groups

Magma

A magma is a pair $(M,\star)$ with a set $M$ and a binary operation $\star: M \times M \to M$ on $M$. Usually, we write $A \times B$ for the collection of pairs of elements of $A$ and elements of $B$. However, it's not possible to write the collection of magmas this way. Note that the second element of the pair $(M,\star)$ depends on the first: $\star$ is a binary operation on $M$, so we need to know what $M$ is before we can define what kind of thing $\star$ is. We call $(M,\star)$ a dependent pair: the type of the second element depends on the value of the first. For a type $A$ and a family of types $B_a$ for $a \in A$, there is a type denoted $(a: A) \times B_a$, $(a: A, B_a)$ or $\sum_{a: A} B_a$ called the dependent sum type. For $a \in A$ and $b \in B_a$, we have that the pair $(a,b)$ is an element of $\sum_{a:A} B_a$. For example, the type of magma's described above is denoted as $\Magma := \sum_{M:\Set} [M \times M,M]$. The usual product is a special case of the dependent sum where the type $B_a$ does not depend on $a$.
